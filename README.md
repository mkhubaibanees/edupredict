# 🎓 EduPredict AI

**EduPredict AI** is a modern Educational SaaS dashboard concept built with Next.js and React. It features a multi-portal architecture designed for admins, teachers, students, and parents, with a strong focus on clean UI, reusable components, responsive layouts, and scalable frontend structure.

🔗 **[Live Demo](https://edupredict-omega.vercel.app/)**

## 🌟 Multi-Portal Architecture

EduPredict AI includes four dedicated dashboard experiences:

- **🛡️ Admin Portal:** Institutional analytics, system overview, and administrative controls.
- **📚 Teacher Portal:** Class management, student tracking, grading interfaces, and academic insights.
- **👨‍🎓 Student Portal:** Personalized dashboard, progress tracking, assignments, and learning activities.
- **👪 Parent Portal:** Student progress monitoring, performance insights, and engagement overview.

## ✨ Key Features

- Four dedicated user portals
- Modern SaaS dashboard interface
- Responsive layouts for desktop and mobile
- Complex data tables and analytics views
- Reusable React components
- Smooth interface animations
- Dark-mode focused UI
- Demo pricing and SaaS landing page
- Clean and scalable frontend architecture

## 💻 Tech Stack

- **Framework:** Next.js (App Router)
- **Library:** React
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mkhubaibanees/edupredict.git
cd edupredict
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## 🎯 Project Purpose

EduPredict AI was built to demonstrate frontend development skills in modern SaaS dashboards, including multi-role interfaces, reusable component architecture, responsive design, data-heavy layouts, and polished user experiences.
